# 项目背景与研究目标

“货币战争智能狸”是《崩坏：星穹铁道》玩法“货币战争”的 Windows 辅助软件。现有程序已具有截图、页面/字段识别、对局记录和 Advisor 基础契约。下一阶段需要用可追溯攻略为实时建议提供依据。

本研究包只负责攻略知识层：

- 多来源收集攻略；
- 保留来源证据、版本、时间点和不确定性；
- 把结论转换为可校验、可版本升级、可由程序读取的声明式规则；
- 用标准 ID 连接当前项目的角色、装备、羁绊、投资环境和投资策略；
- 对冲突、不完整信息和版本漂移安全降级。

本包不授权外部 AI 修改主程序代码，不要求运行游戏或来源不明的软件，也不允许执行攻略 JSON 中的任何内容。

## 当前兼容基线

- 游戏资料版本：4.4。
- 现有 Advisor 运行时格式：`schemaVersion: 1.0.0`。
- 新研究格式：`research-evidence.v1`。
- 新攻略格式：`guide-playbook.v1`。

新格式保留了现有 Advisor 的核心概念：guide、archetype、goal、signals、conditions、unknown policy、rules/actions、risks 和 evidence；同时补齐独立证据层、逐阶段推荐状态、复杂分支、替代路线和冲突保留。正式运行时可通过映射适配，不需要维护第二套互相矛盾的实体 ID。

## 成功标准

每条重要攻略结论都能从 playbook 的 `evidenceRefs` 找到具体 evidence claim，再定位到公开来源 URL 和文章章节/视频时间点。无法确认的内容不驱动高风险决策。
