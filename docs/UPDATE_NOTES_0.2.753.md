# 货币战争智能狸 0.2.753 更新说明

- 修复详细历史窗口关闭按钮被标题栏拖动事件吞掉的问题：拖动事件只绑定独立标题区域，不再覆盖关闭按钮。
- 详细历史只接受 `1-1`、`2-4` 等真实节点编号；`Battle`、`battle_generic`、`reward_shop` 等页面标签会归入最近的真实节点，不再生成空白伪节点。
- 完美规则补齐：血量变化 `+2` 判定完美；血量变化未知且剩余行动严格大于 `10` 时判定完美，行动等于 `10` 不推断。
- 伤害单位缺失时不再把推测的“万”位候选直接当作最终伤害，也不允许两帧相同的单位缺失候选自动升级为可信值；保留原始 OCR 和不确定原因。
- 详细历史窗口改用更清晰的字体、文字层级、金色/青色信息强调、细线选中状态和自定义窄滚动条，移除系统默认白色滚动块。

验证范围：使用与本次修改直接相关的轻量定向测试和 Release 编译验证。当前机器未安装游戏，未执行实机验证；对于 OCR 已明确输出错误单位而非单位缺失的情况，仍需相应运行日志和失败截图确定，程序不会猜测正确数量级。
