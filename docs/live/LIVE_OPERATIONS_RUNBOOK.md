# 直播操作手册

## 首播前人工确认

- [ ] B站账号本人实名认证完成，直播权限、房间号、分区可用。
- [ ] 从 B站官方页面获取推流信息；直播码只填入 OBS，不截图、不保存到项目。
- [ ] 从 OBS 官方站点安装 OBS Studio；运行自动配置向导。
- [ ] OBS 中能看到 AMD AMF H.264 硬件编码器。
- [ ] 只添加“游戏捕获/指定窗口”，不使用整个显示器捕获。
- [ ] UID 区域有不透明遮罩；切换不同游戏页面确认始终覆盖。
- [ ] Windows 通知、聊天、邮件、剪贴板历史和浏览器密码提示已关闭。
- [ ] 麦克风、游戏音频分别录制测试，监听无回声、爆音或私密通知。
- [ ] `Ctrl+Shift+F12` 能停止助手，日志出现 `EmergencyStopRequested`。
- [ ] 上传在计划开播时段完成 30 分钟测试；OBS 丢帧和编码过载均为 0 或可解释的极低值。
- [ ] 完成一次“不推流本地录制”的完整代刷演练并回看。
- [ ] 明确告知自动化第三方工具风险，不承诺账号绝对安全。

## 推荐 OBS 初始参数

- 画布：2560×1440（与显示器一致）。
- 输出：1920×1080。
- 帧率：首轮 30 fps；稳定后测试 60 fps。
- 编码器：AMD AMF H.264 硬件。
- 码率：CBR 4500–6000 kbps，最终服从 B站直播中心当前限制。
- 关键帧：2 秒。
- 音频：AAC 160 kbps，48 kHz。
- 录播：先使用与直播相同编码器，存储到 D 盘；确认负载余量后再分离编码。

## 每次开播顺序

1. 运行性能监控脚本，将日志写到 D 盘或项目外的专用目录。当前电脑需使用以下一次性绕过命令（不会修改系统执行策略）：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\Codex-2\tools\Start-LivePerformanceMonitor.ps1" -DurationMinutes 120
   ```

   脚本记录系统 CPU、可用内存及游戏/助手/OBS 的进程内存、累计 CPU、线程和响应状态；GPU 编码占用、编码过载、渲染延迟和网络丢帧仍以 OBS“统计信息”窗口为准。

2. 启动游戏并固定窗口大小；启动助手，先执行只读截图检查。
3. 启动 OBS，停留在“等待”场景；检查来源、UID 遮罩和音频表。
4. 本地录制 2 分钟，检查画面、声音、CPU/GPU、丢帧。
5. 用户手动登录直播中心、填写标题/分区并开始推流。
6. 确认直播间画面和声音后，再启动自动重刷。
7. 自动化运行期间不切走游戏，不在该桌面开发；用手机看弹幕。

## 代刷排队流程

1. 观众只提交：希望的开局条件、是否接受特殊规则、可等待时间。
2. 不接收密码、验证码、Cookie、远程控制码或支付信息。
3. 需要玩家账号时，由玩家本人在不直播的隐私场景中登录；主播不记录凭据。
4. 开始前复述目标条件和风险，取得明确同意。
5. 每个请求分配匿名队列号，不在画面显示用户名与联系方式。
6. 完成后记录：队列号、配置摘要、结果、耗时、错误码；截图入库须另行同意并遮挡 UID。

## 事故处理

### 自动化失控或重复输入

1. 按 `Ctrl+Shift+F12`。
2. 切 OBS 到“暂停/故障”场景并静音桌面音频。
3. 确认助手状态为停止；如未停止，关闭助手窗口。
4. 不盲目重复点击，保存日志和最后一张脱敏截图。
5. 人工确认游戏状态后决定恢复或终止该请求。

### 游戏掉线/崩溃

1. 停止助手，切暂停场景。
2. 不在直播画面内输入账号、密码或验证码。
3. 恢复游戏后先做只读截图检查，再重新启动自动化。

### 推流中断

1. 不操作游戏输入链路；先确认 OBS 网络状态。
2. 若自动化仍安全运行，可让其完成当前受控步骤后停止；否则立即急停。
3. 检查 Wi-Fi/路由器，不同时启用两个无明确用途的网络适配器做切换实验。

### 隐私泄露

1. 立即切换全屏遮挡并停止录制/推流。
2. 撤销直播码、令牌或会话；修改已暴露的凭据。
3. 删除或申请下架包含敏感内容的录播片段。
4. 记录泄露范围和处理结果。

## 直播文案草案

标题：`《货币战争》开局重刷实测｜免费开源小助手开发直播`

简介：`现场演示货币战争开局条件筛选与稳定性测试，欢迎提交规则组合和失败截图。工具只使用画面识别与 Windows 输入，不读取/修改游戏内存，不注入游戏进程。第三方自动化可能存在账号风险，请充分了解后自行决定是否使用。`

常见问题：

- 是外挂吗？——不读写游戏内存、不注入、不改游戏文件；但自动化仍属于第三方工具，不能保证平台或游戏官方认可。
- 免费吗？——当前项目 README 定位为免费、源代码公开；正式下载地址和许可证在发布前必须再次确认。
- 能边刷边用电脑吗？——当前稳定版不行，失焦会安全暂停；后台输入仍是待实机验证的实验方向。
- 能代登录吗？——不接收密码、验证码或 Cookie，账号始终由玩家本人控制。
- 出错怎么办？——全局急停为 `Ctrl+Shift+F12`，之后保存脱敏日志和截图排查。
