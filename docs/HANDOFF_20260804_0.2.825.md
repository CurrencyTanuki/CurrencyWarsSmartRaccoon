## 一、项目是什么（背景知识）

**货币战争智能狸**（CurrencyWarsSmartRaccoon）：面向《崩坏：星穹铁道》「货币战争」玩法的 Windows 桌面辅助工具。

- **技术栈**：C# / .NET 8 / WPF（App）+ Vision（截图/模板/OCR）+ Tasks（采集/自动化）+ Advisor（攻略建议骨架）。
- **核心约束**：只做截图识别 + OCR + 模拟输入；**不读游戏内存、不注入进程、不改游戏文件**。
- **运行要求**：管理员权限（`app.manifest` `requireAdministrator`，与游戏同权限级，否则 UIPI 静默拦截鼠标/键盘注入）；游戏客户区 16:9（实测 1920×1080、2560×1440）。
- **用户环境**：i5-13400F + RX 7650 GRE + 2560×1440；游戏以**云游戏模式（Edge 浏览器）**为主。
- **项目根**：`C:\Users\zzz81\AppData\Roaming\reasonix\global-workspace\CodexHandoff-20260802\CurrencyWarsSmartRaccoon-CodexHandoff-20260801`

### 关键工程常识（血泪教训，勿重蹈）
1. **输入注入无效 = 权限问题**：先查完整性级别（游戏管理员运行，软件必须 requireAdministrator）。0.2.771-775 换了 MoveMouse 实现都不动，0.2.776 改 requireAdministrator 才恢复。
2. **OCR 并发安全**：PaddleOCR ONNX session 非线程安全，同一 session 并发 Run 会 c0000005 崩溃。用每 lane 独立 session 池（`PpOcrOfflineOcr`，maximumConcurrency 6）。
3. **改识别/关键帧/页面逻辑必须真实帧回放测试**（`tests/.../Fixtures/` 真实截图），只跑模拟帧单测视为未验证。
4. **测试通过 ≠ 实机认可**：全量全绿也可能被用户实机打回（0.2.752-755 全绿但用户否决）。交付列"需实机验证点"。
5. **累积制**：用户反馈先入 `docs/PENDING_USER_FIXES.md`，用户说"一起修"才统一修复+全量回归+出 1 个候选版（版本号递增、可回退包并存）；阻断级 bug 可立即修。
6. **单变量修改**：一轮只改一个行为变量；性能改动记录前后基线。
7. **交付物 = publish 目录 + exe 完整路径**（不打 zip）；交付后软件保持运行不关闭。
8. 用户反感"平衡方案/兜底方案"：必须治本（改识别/改根因）。

2. **云游戏窗口截屏黑屏 / 无法截取**

   - 修复（`src/CurrencyWarsAssistant.Vision/GdiGameCapture.cs`）：
