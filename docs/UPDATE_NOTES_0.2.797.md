# 0.2.797 更新说明（2026-08-03 14:15）

## 修复：快速路径"盲点连点后卡在等位面进度页"（0.2.796 实测 14:10 日志）

### 现象
0.2.796 实机（14:09:43 启动会话）：
- 14:10:18 快速路径正常触发："点击开始货币战争后盲点连点开始本局 4 秒" ✓
- 14:10:25 起程序一直等 `plane_progress/plane_progress_continue` 模板
  （置信度仅 30.7%~33.2%，阈值 90%）→ 永远等不到 → 卡死
- 画面实际已到敌人概览页（截图实锤：3 阵营卡片）

### 根因
`CurrencyWarsNavigation.cs` 中敌人概览确认后的快速分支：
盲点连点"位面进度继续"(960,720) 3 秒后，等待页面时用了
**enemy_overview_next 动作的 ExpectedPageIds = [plane_progress]**——
但盲点 3 秒后画面早已过了位面进度页，到了投资环境页，
程序却还在等 plane_progress（已过去的页面）→ 等不到。

### 修复
盲点 3 秒后等待目标改为 **investment_environment**
（位面进度页的继续动作的 ExpectedPageIds），与用户方案一致
（"接着继续每隔 0.05 秒点击，持续3秒，然后开始识别投资环境"）。

### 附带说明
- 14:10:14 第一次导航失败"已识别挑战失败"：启动时游戏停在上一局的
  挑战失败结算页（正常保护，非 bug）；PassiveRecovery 检测到安全入口
  页（currency_wars_home）后自动恢复，14:10:18 正常进入快速路径。
- 盲点连点间隔已在 0.2.796 改为 0.1s（用户要求）。

## 测试
