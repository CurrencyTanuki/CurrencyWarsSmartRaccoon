# 数据与攻略知识库对话交接约定

- 状态：上游独立对话已存在
- 所属边界：只生产原始资料与可追溯来源，不直接决定运行时模型
- 当前运行时版本：4.4

## 上游可以交付

- 角色、羁绊、装备、投资环境、投资策略、竞争对手、敌人词条；
- 攻略流派、运营策略和来源信息；
- 原始图片、别名、版本、来源链接和研究备注；
- 新字段和暂时无法被运行时消费的信息。

## 上游不应直接修改

- `src/` 中的 C# 运行时模型和自动化流程；
- 已发布候选产物；
- 总控正在维护的 `docs/PROJECT_STATUS.md`、`ARCHITECTURE_BOUNDARIES.md`、`DECISIONS.md`；
- 运行时 `data/4.4/`，除非总控明确分配了目标文件且确认没有并发写入。

## 总控接收流程

1. 把上游 JSON 作为 raw 输入保存；
2. 检查 schema 版本、游戏版本、ID、枚举、必填字段和引用；
3. 记录字段映射和无法消费的字段；
4. 运行可重复的转换工具；
5. 校验生成的运行时 JSON；
6. 运行 `GameDataCatalog` 及引用测试；
7. 确认 App 启动装载与模板引用；
8. 更新数据导入记录和项目状态。

## 当前缺口

现有 `tools/Import-GameData.ps1` 只支持从四份特定 Markdown 报告提取投资环境、投资策略、敌人词条和竞争对手，并用固定数量做最低校验。角色大 JSON 已直接存在 `data/4.4/`，但还没有通用 schema、raw/runtime 分层、跨文件引用校验或转换报告。

在这些缺口补齐前，任何新的上游 JSON 都不得因为“能被 `JsonSerializer` 解析”就直接视为可接入。
