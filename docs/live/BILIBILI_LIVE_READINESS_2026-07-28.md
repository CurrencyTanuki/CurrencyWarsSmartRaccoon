# B站直播并行运行调查与准备报告

日期：2026-07-28

## 结论

当前电脑的计算性能和磁盘空间足够承担《崩坏：星穹铁道》、货币战争小助手、OBS 硬件编码直播和开发工具。当前真正的限制不是性能，而是输入焦点和网络上行余量：第一阶段自动化使用 Windows `SendInput` 移动全局系统鼠标，并在游戏失去前台焦点时暂停，因此不能与同一 Windows 桌面上的自由鼠标操作同时进行；第二阶段只读局势收集不发送输入，可以和开发、直播并行。

单机低成本方案可以立即试播，但“自动重刷期间同时自由开发”目前不成立。长期最稳妥的方案是第二台电脑运行游戏和自动化，当前电脑运行 OBS、开发工具和直播管理。单机后台输入只能作为黑盒实验功能，在游戏实测通过前不得替换现有输入后端。

上传测试是一次短时快照，不是运营商 SLA。正式直播前必须在实际时段完成至少 30 分钟的 OBS 本地录制和私密/测试推流，并观察丢帧、网络抖动与编码过载。

## 项目输入与捕获链路

- 启动项目是 `src/CurrencyWarsAssistant.App`，目标框架为 `net8.0-windows10.0.19041.0`，WPF。
- `Win32InputController` 将游戏客户区坐标转换为屏幕坐标，调用 `NativeWin32InputBackend` 的 `SendInput` 发送绝对鼠标移动、按下、抬起和键盘输入。
- `SendInput` 返回成功只表示事件进入 Windows 输入流，不代表游戏已经接受动作；现有流程通过后续截图验证界面变化。
- `GameForegroundGuard` 要求游戏窗口持续为前台；失焦后每 250 ms 检查一次，重新获得焦点并稳定 250 ms 后才继续。
- 当前生产截图实现是 `WindowsGraphicsGameCapture`，按指定游戏窗口捕获，不依赖屏幕上是否被其他普通窗口遮挡；窗口关闭、最小化或捕获会话失效仍可能失败。
- 第二阶段 `Phase2LiveCollectionService` 明确为只读采集：普通页面约 2 秒一次、战斗约 3 秒一次，不发送鼠标或键盘输入。
- 已有全局紧急停止热键 `Ctrl+Shift+F12`，另有界面“停止”按钮；自动重刷有取消令牌、最长运行时间和有限重试。

## B站开播必要条件和当前缺口

### 账号和平台

- 账号本人完成实名认证；平台协议明确未完成或未通过实名认证可能无法开播。
- 在直播中心确认账号已有直播权限、房间号、游戏分区以及当前可用的开播方式。账号状态只能由用户登录后确认，本次没有登录或修改账号。
- 从直播中心或官方直播工具获取推流地址和直播码。直播码属于密钥，禁止写入仓库、截图、日志或直播画面。
- 开播前再次阅读当前《直播服务协议》《主播直播规范》和游戏分区规则。

### 软件和编码

- 推荐安装官方 OBS Studio；也可使用 B 站直播姬。OBS 官方建议先运行自动配置向导、添加 Game Capture/Window Capture、配置音频并进行测试录制。
- 此显卡优先选择 AMD AMF H.264 硬件编码，CBR，关键帧 2 秒。具体可用编码器必须在 OBS 安装后确认。
- 初次稳定性方案：1920×1080、30 fps、4500–6000 kbps 视频、160 kbps AAC。若 30 分钟实测稳定且 B 站后台允许，再升级到 1080p60；不要依据一次测速直接上 1440p。
- 推流码率必须服从直播中心当时显示的上限和推荐值。B 站帮助中心明确要求根据上行测速选择码率，并推荐 10 Mbps 独享宽带、条件允许时 20 Mbps 以上。

### 场景和来源

1. `等待`：项目 Logo/文字、开播倒计时、无桌面内容。
2. `自动重刷`：优先 OBS 游戏捕获；只显示游戏与经裁剪的助手状态，不捕获整个桌面。
3. `开发说明`：仅捕获专门准备的演示窗口，不显示终端环境变量、源码路径、浏览器账号或私聊。
4. `暂停/隐私遮挡`：全屏静态图和静音，任何登录、验证码、切换账号、故障处理前立即切入。
5. `故障`：明确提示“自动操作已停止，正在人工检查”，不展示崩溃堆栈和本地路径。

### 音频和互动

- 桌面音频只捕获游戏应用音频，避免全局通知音。
- 麦克风使用噪声抑制、噪声门和限幅器；正式直播前录制试听。
- 弹幕管理优先放在手机或第二设备；单机自动化运行时不要点击桌面弹幕窗口。
- 录播与直播使用分离音轨时会增加编码/磁盘负载，首轮先使用“与直播相同编码器”验证稳定性。

## 隐私清单

- 游戏 UID：游戏画面通常固定显示，必须用 OBS 场景遮罩覆盖，不能只依赖裁剪偶然避开。
- 推流地址、直播码、B 站 Cookie、邮箱、手机号、验证码、二维码：永不出现在源代码、配置模板、日志和画面中。
- Codex/IDE：隐藏工作区绝对路径、临时文件路径、Git 远端、令牌、环境变量、私有提示词和其他用户材料。
- Windows：关闭通知横幅、剪贴板历史弹窗、邮件/聊天预览和云盘同步提示。
- 代刷玩家：不接收密码，不要求转移账号；玩家本人登录并保持账号控制。截图入库前取得授权并遮挡 UID。

## 合规与封号风险

已有其他主播长期展示类似工具、形成社区，是有价值的现实观察，说明风险并非必然立即发生；但这不是官方许可，也不能推出“不会封号”。HoYoverse 条款保留反作弊检测，并限制可能造成不公平优势或干扰服务的软件、脚本和程序。公开直播会增加行为可见性，因此风险应按“存在且无法由本项目保证”处理。

底线：不读取或修改游戏内存，不注入游戏进程，不安装游戏 Hook，不修改游戏文件、驱动、反作弊组件或网络流量，不调用内部接口。只允许屏幕/窗口截图、OCR/模板匹配和公开 Windows 输入接口。用户应使用自己愿意承担风险的账号进行测试，并在直播简介和代刷授权中明确说明。
