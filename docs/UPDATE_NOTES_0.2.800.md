# 0.2.800 更新说明（2026-08-03）

## 以 0.2.790 为基线的方案重写（0.2.791~0.2.798 视为不存在）

### 0-1 延时取消
- 切换游戏窗口到前台后的 200ms 等待已删除：直接刷新验证前台，不再等待。

### 快速刷开局盲点连点（标准博弈，Fast/Extreme 模式启用）
- **主界面 → 开始本局**：点"开始货币战争"(1590,976) 后，**不再识别中间页面**，
  每 0.05s 盲点连点"开始本局"(1690,967)，持续 4 秒（80 次）；
- 停止后等**敌人概览稳定识别**（保留），识别后点确认(1514,985)；
- 确认后每 0.05s 盲点连点"位面进度继续"(960,720)，持续 3 秒（60 次）；
- 然后识别投资环境（识别逻辑不变）；
- **点选投资环境**：点选 → 0.05s 复点 → 50ms → 直接点确认(1083,984) 不检查 → 进 1-1。

### 备战页调整
- 识别到完整备战页**立即识别角色**（InitialPreparationSettleDelay = 0）；
- 备战席识别重试 550ms → **200ms**；
- 部署/出售拖拽：650ms 拖拽 + **50ms** 等待；
- **去掉备战席占用复核**：开矿前不再复核占用，直接允许开晶矿球
  （开矿动作本身保留，在商店后执行）；
- **页面确认并行化**：每次操作前不再等双帧确认，单帧确认即继续。

### 设置页新增"快速刷开局模式"3 选项
- **稳定版**（默认）：当前完整识别与验证流程；
- **快速版**：去掉备战页全部验证，OCR 只识别两次（开局一次 + 商店补员一次），
  其余按内部状态机推算（规划→裸拖拽→补位）；
- **极速版**：备战席前三个角色无脑拖到前台 1/2/3 号位，不识别、不规划、
  不验证，其余备战逻辑全部去掉。

### 自动战斗检测重写
- **快速检查**：每 0.2s 一次（窗口 2 秒）：
  - 连续 2 帧 Disabled → 按 V 开启；
  - 连续 3 帧 Enabled → 提前确认开启，转入慢速；
- **慢速检查**：每 2s 一次；
- V 发送后回到快速检查（0.2s×2s）验证；
- 连续 3 次 V 仍未确认 → 停止切换，只监测战斗结果。

### 1-2 备战节点
- 复用 1-1 全套逻辑（CompleteAfterShopAsync/CompleteAfterShopFastAsync
  按 expectedPreparationPageId 区分 1-1/1-2）。

### 开晶矿逻辑确认
- 存在：EnsureMineCapacityAsync（容量检查）→ 打开商店 →
  OpenMineBallsWithCapacityGuardAsync → 检测晶矿球并点击开矿。
  备战页只显示"开矿前检查"日志，开矿动作在商店后执行。
