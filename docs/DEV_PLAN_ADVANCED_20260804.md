# 货币战争智能狸 · 进阶开发流程计划报告

（2026-08-04，基于 Codex 评估 + SRA 竞品分析 + 用户方案）

## 一、战略定位（Codex + SRA 分析结论）

- **差异化定位**：专业的《货币战争》开局筛选、局势识别、运营记录、复盘报告和可解释决策平台
- **不要正面竞争**：刷开局（SRA 重叠 80-90%）、综合自动化、自定义攻略（SRA 已有）
- **应坚持优势**：局势数据记录（SRA 没有）、可解释实时建议、多分辨率、Unknown 降级
- **现实目标**：先 200-500 人测试群 → 500-2000 人垂直社群；准备度 4/10 → 先建可信发布基础

## 二、攻略资产现状（已收集，在桌面 guide-research-v1.0.0）

- **31 份 research-evidence**（B 站/4399 真实攻略证据）：狼狩万敌、姬子白厄反震、双神君枪兵景元、千冶刃、试用姬子 A850 通关、闪大王逃课 bug 等
- **16 份 guide-playbook 攻略 JSON**（已整理）：万敌主线/姬子三路线/符玄阿瓦隆锁血/丹恒盾/黑龙反击/通用经济止损/白厄反震/花火等
- **schema**：guide-playbook.v1.schema.json（格式定义）
- **tools**：校验工具、standard-ids、output-template

**结论**：攻略数据已齐，缺的是**集成进软件**（复制到 data/advisor/guides 供 GuideRepository 加载）

## 三、执行顺序（用户确认的优先级）

### 阶段 1（先做）：跑通基础局势分析
1. **集成攻略**：把桌面 16 份 guide-playbook 复制到 `data/advisor/1.0.0/4.4/guides/`
2. **验证加载**：GuideRepository 能读到（确认 schema 兼容）
3. **确认建议展示**：SituationAnalysisViewModel → AdvisorEngine 输出真实建议，主界面可见

### 阶段 2：适配
1. **云游戏适配**：目前只识别浏览器窗口，需完整接管
2. **UI 缩放适配**：历史看板 600×620 固定 → 2K+150% 下缩小/自适应；日志悬浮窗同理

### 阶段 3：攻略基础设施 + 社区共创
1. 攻略 JSON 校验器（坏攻略跳过不崩）
2. 攻略版本字段（game_version，版本不符降级提示）
3. 投稿渠道 + 审核 + 署名（"by xxx"）
4. 投稿教程文档

### 阶段 4：验证 + 宣传
1. 30~100 真实用户验证漏斗
2. 视频宣传"局势数据记录 + 实时建议"（差异化主题，避开刷开局）

### 远景：实时陪玩智能体
- 银狼式 AI 陪玩：实时建议 + 聊天 + 实时合成自然人声
- 复用 video-pipeline 的 CosyVoice 双音色资产（道歉/得意）
- 实时合成/渲染/播放

## 四、当前待办（下一步具体动作）

1. 【阶段1-1】复制桌面 guide-playbook 到 data/advisor/guides + 验证加载
2. 【阶段1-3】确认局势分析 UI 展示
3. 然后进入阶段 2（适配）

## 五、风险与注意

- 攻略 JSON 需与 schema 兼容（先校验再集成）
- 游戏更新后攻略需同步（版本字段）
- 社区投稿需审核避免错误攻略
- 封禁风险：不宣传"绝对安全"
