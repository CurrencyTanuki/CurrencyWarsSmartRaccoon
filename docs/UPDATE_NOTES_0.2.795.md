# 0.2.795 更新说明（2026-08-03 深夜）

## 按用户方案实施的刷开局全面优化

### 1. 启动阶段
- 取消"切换游戏窗口到前台"后的 200ms 等待（0-1）：直接刷新验证前台，不再等待。

### 2. 快速路径（标准博弈，快速版/极速版启用）
- **主界面 → 开始本局**：点"开始货币战争"(1590,976) 后，**不再识别中间页面**，
  每 0.05s 盲点连点"开始本局"(1690,967)，持续 4 秒（共 80 次）；
- 停止后等待**敌人概览稳定识别**（保留识别），识别后点确认(1514,985)；
- 确认后**每 0.05s 盲点连点"位面进度继续"(960,720)，持续 3 秒**（60 次）；
- 然后识别投资环境（识别逻辑不变）；
- **点选投资环境**：点选(439,530 实际槽位) → 0.05s 后复点一次 → 50ms 后
  **直接点确认(1083,984)，不检查页面** → 进入 1-1。
- 稳定版（默认）仍走完整逐步识别流程，不受影响。

### 3. 备战页调整
- **立即识别**：识别到完整备战页后立刻开始识别角色，不再等 1400ms 入场稳定；
- **识别重试** 550ms → 200ms；
- **部署/出售拖拽**：650ms 拖拽 + 50ms 等待（原 500ms）；
- **去掉备战席占用复核**：开矿前不再 4 次复核占用，直接允许开晶矿球
  （开矿动作本身保留，在商店后执行）；
- **页面确认并行化**：每次操作前不再等 200ms 双帧确认，单帧确认即继续；
  页面切走时由各操作自身监测停止。

### 4. 设置页新增"快速刷开局模式"3 选项
- **稳定版**（默认）：当前完整识别与验证流程；
- **快速版**：去掉备战页全部验证，OCR 只识别两次（开局一次 + 商店补员一次），
  其余按内部状态机推算（规划→裸拖拽→补位）；
- **极速版**：备战席前三个角色无脑拖到前台 1/2/3 号位，
  不识别角色、不做规划、不做验证，其余备战逻辑全部去掉。
- 默认值保持"稳定版"，未改动用户设置。

### 5. 自动战斗检测重写
- **快速检查**：每 0.2s 一次（窗口 2 秒）：
  - 连续 2 帧 Disabled → 按 V 开启；
  - 连续 3 帧 Enabled → 提前确认开启，转入慢速；
- **慢速检查**：每 2s 一次（确认开启后或快速窗口耗尽）；
- V 发送后清空观察，回到快速检查（0.2s×2s）验证；
- 连续 3 次 V 仍未确认 → 停止切换，只监测战斗结果。

### 6. 1-2 备战节点
- 1-2 复用 1-1 同一套备战逻辑（CompleteAfterShopAsync 按页面 ID 区分），
  快速版在 1-2 同样走"商店补员单帧识别 + 裸拖拽"。
