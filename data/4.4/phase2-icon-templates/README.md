# 第二阶段本地补充图标库

每个子目录名就是识别类别，图片文件名格式为 `<稳定ID>__<可选说明>.png`。程序启动时递归加载 PNG，不需要修改识别流程。

另一 AI 提供的 4.4 完整资产包已经导入相邻目录 `../phase2-icon-assets/`，并由带版本、来源和多义候选信息的 `asset-manifest.jsonl` 加载。此目录继续保留给用户后续提供的本地截图模板：

- `synergy/`：经过真实截图验证的羁绊补充模板；
- `negative-affix/`：开局负面词条图标；
- `investment-environment/`：投资环境图标；
- `investment-strategy/`：投资策略图标。

不要把来源不明或含义未确认的图片命名为确定 ID。完整资产库中的同图多义条目不会输出为确定结果；未命中的槽位会保存原始裁剪、最佳候选、候选 ID 和置信度，供补充模板后重新处理。
