# 备战、奖励关与投资策略

## 模块目标

在开局方案已经命中并锁定后，分阶段识别备战席、规划/验证布阵、处理前两层奖励关、商店与晶矿球、自动战斗，并按锁定方案选择首个投资策略。

## 不属于本模块的内容

不重新判断开局是否命中、不修改多方案语义、不拥有底层捕获/OCR 算法、不绕过前台保护、不直接导入上游知识 JSON，也不决定该实验能力是否具备发布资格。
