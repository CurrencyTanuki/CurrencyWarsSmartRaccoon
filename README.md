# 货币战争小助手

一个面向《崩坏：星穹铁道》货币战争玩法的免费、源代码公开 Windows 桌面工具。

当前项目名称为“货币战争小助手”，包含自动重刷开局、对局状态记录、历史节点看板和挑战总结等能力。

当前开发范围是开局筛选：

- 自动发现游戏窗口；
- 截取游戏客户区；
- 通过页面锚点和 Windows 本地中文 OCR 读取开局；
- 投资环境允许用户选择任意多个可接受项；三个候选命中任意一个即合格，未选择则默认全部接受；
- 敌人阵营和负面词条分别支持“不限制 / 必须出现 / 必须刷掉”；
- 支持跨类别的必须出现或必须不出现组合；
- 只判断当前组合是否满足用户条件，不对不同流派作统一强度评分；
- 在自动模式下执行带前置检查和后置验证的鼠标点击；
- 未知页面优先使用 Esc 恢复并重新识别；可恢复的 OCR 不确定结果持续重试。

## 当前状态

自动化内核、桌面筛选页、真实页面模板和 4.4 数据包已经建立。当前版本可以：

- 发现正在运行的《崩坏：星穹铁道》窗口；
- 截取并预览游戏画面；
- 从普通游戏 HUD 自动进入货币战争；
- 识别并关闭更新说明、积分奖励弹窗；
- 识别敌方三个阵营、四个负面词条和三个投资环境；
- 配置投资环境可接受列表，以及敌人阵营、负面词条的正选或反选；
- 使用内置“灰手生命科技 + 额外打击”禁止共存规则，或通过弹窗添加自定义组合；
- 首轮三个投资环境均未命中偏好时使用一次免费刷新并重新识别；
- 条件吻合时停止；刷新后仍无可接受投资环境或命中排除条件时退出并结算；
- 在单次流程测试中选择第一个投资环境并导航到首次备战。

不合格开局的退出、放弃结算和返回主界面流程已经接入，目前仍需继续通过实机测试校准动画等待和各中间页面。

## 使用顺序

1. 启动游戏，停在普通游戏 HUD 或流程中任一已支持页面；
2. 启动本工具；
3. 点击“重新查找窗口”；
4. 点击“截取当前画面”确认捕获正常；
5. 按需选择可接受投资环境，并配置敌人阵营与负面词条的“必出 / 刷掉”；投资环境留空表示全部接受；
6. 按需点击“添加组合规则”，选择两个不可同时出现的条件；
7. 首次使用先点击“仅识别并判断一次”，对照游戏画面核验 OCR；
8. “导航到首次备战”用于无条件流程测试，会选择第一个投资环境；
9. 完成一次退出结算实机验证后再使用连续自动刷取。

## 安全边界

- 不读取或修改游戏内存；
- 不注入游戏进程；
- 不修改游戏文件；
- 只通过画面识别和 Windows 输入接口工作；
- 每个点击目标必须来自当前截图；
- 每个工作流步骤可以配置点击后的预期页面锚点；
- 未配置工作流时拒绝自动点击。
- 可随时按 `Ctrl+Shift+F12` 紧急停止当前任务。

第三方自动化工具可能违反游戏用户协议或带来账号风险。使用者应自行了解相关规则并承担使用风险。
