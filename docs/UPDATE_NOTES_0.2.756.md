## 0.2.756 修复清单

### 回归修复
1. **启动"了解并继续"按钮失效**（0.2.755 引入）：声明窗口改为非模态 `Show()` 后，按钮仍执行 `DialogResult = true`，WPF 禁止对非模态窗口设置 DialogResult，抛出 `InvalidOperationException` 被全局处理器吞掉——按钮点击无任何效果且每次产生一条未处理异常日志。已改为统一 `Close()`（对模态/非模态均正确），并新增契约测试。

### 审计中发现的新问题修复
2. **伤害千分位逗号被误当小数点（高危）**：伤害解析把半角逗号一律替换为小数点，导致 `1,234万` 被解析为 `1.234万`（12,340，实际应为 12,340,000，**错 1000 倍**）。新增 `NormalizeDamageNumber`：半角逗号后跟 1~2 位数字视为小数点（OCR 小数点误读），否则视为千分位分隔符丢弃；修正 `DamagePattern`/`SettlementAsciiUnitPattern`/`SettlementDecimalPattern` 正则以支持多组千分位。新增千分位解析测试。
3. **完美通关判定防御性修正**：`postBattleHealth == 100` 无条件判 Perfect，若未来血量上限可超 100（pre>100 → post=100 → delta<0）会误判。已加 `healthDelta is not < 0` 约束（当前血量 0–100 校验下该场景不可达，为防御性，不改变现有行为）。
4. **全局热键注册失败静默**：Ctrl+Shift+F12 紧急停止 / Ctrl+Shift+F11 穿透热键注册返回值被丢弃，注册失败（热键被占用）时功能静默失效。已检查返回值并通过任务事件记录警告。
5. **断点存储路径穿越风险**：`SanitizeSegment` 未过滤 `.`/`..`，损坏或恶意的 checkpoint runId 可能导致越界写文件。已显式拒绝 `.`/`..`。
6. **初始化数据刷新异常兜底**：`OnContentRendered` 异步事件无异常处理，非 IO 异常走全局吞异常路径。已捕获并记录错误事件。
7. **透明度滑块边界不一致**：滑块下限 0.3 与模型钳制 0.25 不一致，从设置加载 0.25–0.3 值时 UI 显示与模型错位。已统一为 0.25。
8. **日志悬浮窗定时器空转**：`DispatcherTimer` 仅在窗口关闭时停止，`Hide()` 后仍每 750ms 执行 `SetWindowPos`。已改为随可见性启停。
9. **游戏区域归一化除零风险**：宿主窗口尺寸为 0 时产生 NaN 并导致设置整包保存失败。已加尺寸 >0 保护。
