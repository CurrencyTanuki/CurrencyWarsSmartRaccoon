# Release 1.1.0（货币战争智能狸 · 「刷三星五费」版）

发布日期：2026-08-30
包：`CurrencyWarsAssistant-1.1.0-win-x64.zip`（桌面）

## 新功能：刷三星五费（命运圣杯流派）

主界面左侧导航「刷三星五费」——自动刷「1-3 三星五费」开局：

- **环境筛选**：只接受 067 英雄登场 / 019 命运圣杯邀请（契约 018 已剔除），其余自动重开
- **1-1/1-2**：常规通关 + 商店自动买入命运圣杯成员（同名只买一次，绝不卖出命杯成员与星徽携带者）
- **1-3 决策**：投资策略自动择优（采购专员·彩 > 全是这家伙的错！> 采购专员·金 > 二极管；全未命中选最左不重刷）；开晶矿；命杯成员全部上场
- **商店循环**：见命杯角色立刻买→关商店→上场→应答祈愿→重开；昔涟照买不触发上场仪式
- **祈愿试炼自动应答**（外挂监听器，每局 4 次强制弹框全接）：首档盲选左；奇迹代偿需血≥89 且场上已有 5 费本体；回路过载/行为限制仅当奖励识别为五费聘用书才选；无限之釜单人直接收工、全员视为辅助
- **买经验/卖人**：冲 5 档时先买经验（8 金币）再买成员上场；金币不足按保留线（留 N=星徽数）出售非命杯、非 5 费角色凑钱
- **收工判定**：单人=无限之釜或奇迹代偿（选择时血≥89）；全员=奇迹代偿+本体昔涟在场（收工后追全员由玩家手动完成）
- **滚动录屏**：可勾选（需 ffmpeg），成功局保留 MP4 至软件目录 `Recordings\`，失败局自动删除
- 紧急停止：Ctrl+Shift+F12 或「停止」按钮

## 本版同时包含

- 1.0.0 全部功能与修复
- 旧「1-3 三星五费」实验代码全部移除（本版为新实现，与旧实验版不兼容）

## 环境要求

- Windows 10/11 x64、.NET 8 Desktop Runtime、WebView2（主界面报告）
- 管理员身份运行；游戏客户区 16:9（已适配 1920×1080 / 2560×1440）
- 录屏功能可选装 ffmpeg（未装时勾选录屏会自动打开下载页）

## 已知限制（公开测试版，务必小号测试）

- 本功能首次实机联调，以下项待首跑标定：①备战席聘用书图标的点击定位；②场上↔备战席拖拽的互换吸附时序；③备战席角色装备槽（星徽识别）覆盖度

- 识别预热未完成时启动，首轮弹框检测可能滞后（最长 15 秒）
