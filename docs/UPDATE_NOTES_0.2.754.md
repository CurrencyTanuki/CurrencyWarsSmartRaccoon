# 货币战争智能狸 0.2.754 更新说明

## 本次修复

- 关键画面采样间隔由 200 毫秒缩短到 100 毫秒，降低玩家快速点击“继续挑战”时漏掉黄色成功页的概率。
- 页面切换时除保留快速分类器命中的前序帧外，也保留紧邻切换点的原始前序帧；即使黄色成功页只被截到一帧且快速分类失败，进入下一备战页时仍会把该帧送入完整 OCR。
- `战斗 -> 备战` 被强制视为关键边界，避免结算页未分类时直接跳过上一节点总结。
- 关键帧在 OCR 队列满时不再静默丢弃：保存完整失败截图并写入包含运行 ID、版本号、源截图和原因的 `manifest.jsonl`。
- 详细历史窗口新增 Esc 关闭兜底；窗口打开期间隐藏主悬浮窗的透明点击辅助层，避免透明窗口抢占关闭按钮点击。

## 延续包含的识别和界面修复

- “获得金币总览”作为节点奖励金币读取，和基础奖励、利息、连胜明细以及金币变化保持独立，不互相覆盖。
- 备战金币读取保留商店卡片边缘处的前导数字，测试样本中的 `23` 不再变成 `3`。
- 血量变化 `+2` 判定完美；血量变化未知且剩余行动严格大于 `10` 时判定完美，等于 `10` 时保持未知。
- 缺失伤害单位的候选值不再被猜成可信最终伤害，避免以低置信度结果覆盖已识别的高置信度值。
- `Battle`、`battle_generic`、`reward_shop` 等页面标签不再被当作真实节点；它们只归入最近的合法节点编号。
- 详细历史窗口采用细线边界、分层文字颜色和自定义滚动条，并修复关闭按钮事件冲突。

## 离线验证

- 定向回归：74/74 通过，覆盖金币 `23`、结算总览 `8` 与明细 `2`、黄页单帧、战斗结算、完美判定、节点历史和详细窗口。
- 全量回归：546/546 通过，0 失败，0 跳过。
- 使用仓库内全部 85 个测试夹具文件参与测试项目的离线验证。

## 未验证项

- 当前电脑未安装游戏，未进行实机对局验证。
- 100 毫秒采样和关键边界留帧能显著改善短暂页面捕获，但无法保证捕获仅存在约 16 毫秒且恰好落在两次采样之间的单个渲染帧。
- 如果 OCR 明确输出了错误但形式完整的单位（例如把 `30亿` 直接读成 `300万`），仅凭这一帧不能安全猜回正确值；系统会依靠多帧候选和置信度保留更可靠结果，并保存失败证据供异机定位。
