《1-3 三星五费》自动刷 · 决策树（逻辑基础 · 不写代码）

依据既有三份攻略实现方法 · 软件只做逻辑，爽点动作（拖8投影形成三星）交用户手动 · 所有操作必须在 1-3 备战页内完成、不超出、不再开战

投资环境 血量节点（决策点） 买角色组件 试炼接取 达成终点 重刷 用户手动（爽点） 圣杯/星徽

0 · 输入：用户配置 决策1 · 目标

目标配置（二选一）：
A · 只要 1 个三星5费：条件放宽，任意 5 费角色已形成三星即可（昔涟 / Archer / 银狼LV.999 任一个）收工。
B · 全员三星5费：必须先出昔涟（她三星后给金币，才能续凑其他5费三星）；其余不必定追银狼LV.999。
运行感知（软件实时读取）： hpNow 当前血量 · hpInvest 选投资策略那一刻的前一刻血量 · 投资环境 · 投资策略 · 金币 · 已有角色。都是备战页可读信息。
达成终点判据（已拍板）： 凑齐达成条件即判可成 —— 软件判到“条件齐”就收工报告，8 完美投影仪拖拽等爽点动作由用户手动（软件不代劳、不做界面适配）。
⚠️ 软件不检测难度是否 A4-5 以上/以下——只实时检测血量两个节点（见 N1 / N4）。

1 · 开局：投资环境判定 起点

读开局投资环境 → 决定起手主线（三份攻略的实现方法都对到这层）。

N1 · 读投资环境
  • 英雄登场 (067) → 送 1 个 2星5费昔涟（19节点后上场，连胜提前）→ 天然 5 费本体，直奔奇迹代偿/无限之釜。环境A
  • 命运圣杯契约 (018) → 白送凛(1费)+闪(2费)，完成试炼后送 Archer(5费) → 圣杯线本体齐全。环境B
  • 圣杯转 / 命运圣杯邀请 (019) → 送圣杯星徽(第5圣杯用) / 圣杯转 → 走凑圣杯线。环境C
  • 无上述关键环境 → 环境不可行性高，判定进 重刷（见 RETRY）。
注：英雄登场给的昔涟是“2星5费”，1 张即可当“已有 5 费本体”，后续复制到 9 张才三星。

2 · 血量节点①：选投资策略 关键决策

N2 · 选投资策略那一刻，读 hpInvest
  • hpInvest ≥ 88 → 二极管非必须，策略可选可不选，自然进入后续节点。
  • hpInvest < 88（至1-3备战=84）→ 是否必须二极管，按本次走到哪条达成终点分叉：
    • 主线=奇迹代偿终点（需≥88血）→ 必须刷出「二极管」(STR276，+10血+10上限，位面1) 补到 94≥88，否则奇迹代偿选不了。
      • 命中二极管 → 选它 → 血量 84+10=94 ≥ 88 ✓
      • 没刷到二极管 → 尝试迂回（白银→黄金→白银投资）再凹；仍无 → 进 重刷。
    • 主线=无限之釜终点（不依赖88血，直接给三星Archer）→ 二极管 可选可不选，不必强求，直接进入后续节点（目标A常走此线）。
⚠️ 健康充值(STR139，+30)只在二三位面，1-3(A4位面1)拿不到 → 二极管在 1-3 几乎不可替代。

3 · 购角色（命运圣杯成员）= 组件边界 组件

组件封装的“买角色”逻辑，独立可复用，与决策树解耦。

BUY · 购买商店角色（组件接口）
入参：目标角色数 + 目标角色列表（仅 1/2/3 费圣杯成员 可购：凛/闪/Saber）
行为：在商店逐次购买目标角色；同一角色多次刷到只购一次；命运圣杯成员才购（用于激活羁绊）；激活羁绊后购物即停。
返回：金币是否花完(goldExhausted?) · 剩余金币(goldLeft) · 买到哪些角色(bought[]) · 哪些还没买到(missing[])。
⚠️ BUY 组件只能买到 1/2/3 费角色（商店 5 费概率为0，买不到 Archer/昔涟这些 5 费）；因此 5 费本体（含 Archer/昔涟）一律走 N4 机制来源（祈愿登场·聘书·英雄登场·专家招募），不进 BUY 列表。Archer 虽是圣杯成员，也靠机制拿，不走商店。
组件不负责策略决策，只负责“买”。决策树在调用前决定买谁、是否终止（如金币将尽）。

4 · 凑 4 圣杯 圣杯线

N3 · 圣杯成员达标检查
  • 圣杯成员：凛(1费)/闪(2费)/Saber(3费)/Archer(5费)。
  • 用 BUY 组件 在商店购齐所需圣杯成员（同角色只购一次）。
  • 第 4/5 档用 圣杯星徽 或 圣杯转（圣杯转=羁绊数+1，放任意非圣杯角色上场凑第5档；获取=投资环境/补给/炼金炉）。
  • 开局补给球可凹 炼金炉+钻石+简易装备 → 合成圣杯 → 重铸圣杯星徽。
  • 圣杯成员达成 4 个不够 / 无法凑齐 → 判断本环境无法推进 → 重刷。

5 · 拿 5 费本体（仅奇迹代偿线前置） 本体

N4 · 是否已有 5 费本体，按达成分叉
  • 主线=奇迹代偿终点（需把8投影拖到本体→9张）→ 必须有 ≥1 个 5 费本体在池（全扣金币前必须在手）。
  • 主线=无限之釜终点（直接给三星Archer）→ 无需已有 5 费本体，本体要求可跳过。
  • 本体来源（机制获取，坚决不进商店）：英雄登场(2星5费昔涟) / 祈愿「登场Archer」白嫖Archer / 5费聘书 / 专家招募聘书(167/236)。
  • 奇迹代偿线：目标 A 只要1个 → 任意 5 费本体即可；目标 B 全员 → 必须先昔涟本体（缺她启动资金不足，后续全员续不动）。
  • 若 goldExhausted 而目标 5 费仍未到手 → 无复制目标 → 只能 重刷（顺序绝不能颠倒：先扣金币再拿5费=废）。

6 · 试炼接取 + 血量节点② 关键决策

N5 · 4圣杯后祈愿试炼浮现（与已开发的选择试炼模块匹配）
  • 试炼选择优先级： 无限之釜（诅咒·直接给1个三星5费Archer）> 奇迹代偿（诅咒·8投影仪）> 5费聘书 / 登场Archer > 令咒决议·行为限制（3圣杯=2聘书）> 其他。
  • 血量节点②（重点 · 扣88血试炼卡死分支）：当祈愿试炼浮现「奇迹代偿」(扣88血诅咒)时——
    • 若 hpNow ≥ 88 → 可点 → 选奇迹代偿（主线达成）。
    • 若 hpNow < 88 → 该试炼图标不可点击 → 软件改选另一个试炼；若另一试炼也换不到想要的、且血量无法回升到88 → 本局大概率成不了 → 退出结算重刷（见 RETRY）。
  • 常态无目的试炼兜底（与血量无关 · 不重刷）：若第 1、2 个诅咒试炼都没刷到想要的（无限之釜/奇迹代偿/目标聘书）→ 随机选（默认选左边那个试炼），推进试炼进程而不重刷；行为与已开发的 WishTrialSelectionAutomation 一致（选一侧→确认一次→复查，最多3次）。
⚠️ 奇迹代偿触发门槛 = 4圣杯 + ≥88血；低于88直接选不了（不是代价问题，是门槛不够）。选则扣88血+全金币 → 8完美投影仪；94-88=6血不算输。

7 · 达成终点判定 + 目标分叉 收工判定

N6 · 按其“凑齐即判可成”
  • 达成终点A 无限之釜 → 已直接得 1 个三星5费 Archer → 判“已1个三星”达成。
  • 达成终点B 奇迹代偿 → 已拿到 8完美投影仪 且 目标5费本体已在池 → 判“条件齐、可成”，交用户手动拖 8 投影形成三星。
  • 目标 A 只要1个：任一终点达成 → 收工，报告用户，人工接管。
  • 目标 B 全员：已达 1 个三星(昔涟) → 用昔涟金币 → 续追其他5费三星（银狼LV.999等）→ 全部分支都形成 → 判全员达成；中途无法续 → 重刷。
爽点（用户手动，软件不代劳/不为其做界面适配）用户
拿到 8 完美投影仪后，拖投影仪到已有 5 费本体 → 复制出 8 张 + 1 本体 = 9 张 = 三星5费——这一步由你亲手完成（爽点）。软件到“条件齐”即停，不自动拖、不写拖拽界面。

8 · 重刷/收工 边界

RETRY · 触发再次结算重刷（本局不作数）
  • 开局环境不可行（无英雄登场/圣杯线且无法迂回）→ 重刷。
  • 血量节点① hp<88 且走奇迹代偿线却刷不到二极管 → 重刷（无限之釜线不因此重刷）。
  • 圣杯 4 个凑不齐 → 重刷。
  • 血量节点② 奇迹代偿因 hp<88 图标不可点、另一试炼也换不到想要的 → 重刷。
  • 金币花完而目标5费本体仍未到手 → 重刷。
  • B 全员续追中途无力维持 → 重刷。
约束（硬边界）
  • 全部流程必须在 1-3 节点备战页 内完成；到达 1-3 后不再开战，任何遗漏/未满足 → 直接判本局不成 → 退出结算重刷，不把战斗带出 1-3。
  • 不检测难度档；只检测血量两节点即可。
