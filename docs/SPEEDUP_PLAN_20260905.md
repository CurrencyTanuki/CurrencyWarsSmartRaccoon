# 提速方案（2026-09-05 晚，1.2.89 实测数据驱动）——1.2.91 候选清单

> 来源：热路径静态延迟清单（子代理全量盘点）+ 20:18~21:05 实测轮解剖。
> 实测基线：重刷轮 60-80s（历史最佳 24s、快拒轮 24s）；构成=导航 ~14-17s + 弃局 ~14-17s + **识别流冻结税 30-60s**。
> 受保护不可动红线：坑38 逐卖 1s+I10 复核；拖拽 650ms/12 步与 MouseButtonHoldDelay 250ms；VerifyMoveAsync/VerifyBenchSlotEmptyAsync/星徽双帧自证；商店双帧判据与购买后置验证；requiredPageId 危险输入预检；1.2.89 Esc 认页纪律；击后查主页早停（1.2.63）。

## 冻结税（另案但最高优先）

识别流每 45-80s 冻结（今晚新游戏会话上）= 每轮 30-60s 税、识别占空比 ~50%。1.2.88/89 的看门狗+救援已把伤害压到"每轮 1-2 次 30s 盲窗"，但根因未明。诊断方向（1.2.91 一并或独立批次）：采集服务记录帧间隔统计+WGC 会话状态事件，区分"渐慢 vs 断崖"、区分"重启后即死 vs 独立死亡"、关联游戏模式切换（每轮的转场是否是杀手）。另注意：本会话早段（12:22 实例启动后）也出现过 12:29/12:30 连续冻结后转平稳——"启动后前 30 分钟高脆弱"假说待证。
