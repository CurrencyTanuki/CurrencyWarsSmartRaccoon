### 2. 3-7 整局结束识别（根因：评级页被判 currency_wars_home + currentPageNode 挡路）
- `Phase2LiveCollectionService` 完成检测加"3-7 评级页探测"：
  当 `LastFinalizedNode==3-7` 且 fast 分类 pageId ∈ {challenge_success, currency_wars_home, battle_generic}
  → 对帧跑 `Phase2SettlementSemanticClassifier.TryClassifyAsync`
  → 命中评级页特征（challenge_success + evidence 含"下一步"，
  与节点结算"继续挑战/点击空白加速"区分）→ 判 `FinalSuccess` 自动封装整局。
- 修复前：3-7 打完评级页被判主界面 → 不自动结束 → 用户手动结算
  （ratingText="手动结算（数据可能不完整）"、SSS 评级丢失、延迟约 10 分钟）。
- 风险（review 确认可控）：节点结算页/主界面帧不会误判 FinalSuccess
  （"点击空白加速"/"继续挑战"证据不含"下一步"；主界面无"挑战成功"标题 → 语义分类器返回 null）。

  [[currency-wars-deliverable-selfcontained]]。

### 5. 启动方式：必须 explorer 独立启动（程序"自己关掉"根因）
- 现象：self-contained 包启动正常（StartupCompleted + WarmUpCompleted）后进程消失，
  无崩溃事件、无日志——**被 bash 进程组清理**（之前用 bash 里 PowerShell `Start-Process`
  启动，bash 命令返回即杀进程组；0.2.829 同样模式）。
- **修复**：用 `explorer "<exe 完整路径>"` 启动（进程挂 Windows 桌面进程下，脱离 bash
  进程树），验证 60 秒仍存活（PID 23088）。
- **约定固化**：交付后保持运行一律用 explorer 启动，禁止 bash 内 Start-Process。
