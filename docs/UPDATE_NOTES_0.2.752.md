# 货币战争智能狸 0.2.752 更新说明

- 顶部运行区只保留“开始刷开局”“开始记录”“停止”，删除不会启动持续记录的“识别当前画面”和“进入开局页”及其专用命令代码，避免误操作后历史为空。
- 修正启动耗时统计边界：启动提示窗口的人工停留时间不再计入“主窗口构建”。
- 开局筛选长列表启用回收虚拟化，减少 WPF 首次创建的大量界面控件。
- 修正单次局势分析中敌人概览异步结果过早缓存的问题；等待 OCR 完成后再保存有效敌人信息。
- 修正角色身份仍不确定时累计伤害可能停留在较早、较小读数的问题；未知身份不会再阻止较完整的后续伤害值更新。
- 保持正式历史仅展示已完成节点；未使用临时战斗帧推断节点结果，避免当前节点错位或提前出现。

验证范围：已通过项目内定向离线回归与 Release 构建。当前机器未安装游戏，未执行实机验证。偶发字段漏读仍需用对应运行 ID 的实机日志和失败截图确认具体失败层，不能仅凭现象归因。
