# 游戏术语简表

本表只说明研究字段的使用方式，不替代官方规则。

| 术语 | 在数据中的含义 |
|---|---|
| 位面 | 一局中的大阶段，通常以 1、2、3 标识。 |
| 节点 | 例如 1-1、2-4；playbook 可用 `selector.nodeIds` 精确选择。 |
| 节点类型 | 备战、战斗、奖励、遭遇、首领或 unknown。 |
| 前台/后台/备战席 | 角色在备战页面的不同位置；必须分别表达，不能把备战席当作出阵角色。 |
| 羁绊 | 角色组合形成的阵营或流派效果；使用 `currency_wars_bond_*` 标准 ID。 |
| 投资环境 | 开局获得且一局固定的环境；使用 `investment_environment_*`。 |
| 投资策略 | 对局中获得且不会失去的策略；使用 `investment_strategy_*`。 |
| 简易/进阶装备 | 简易装备可合成为进阶装备；playbook 中都引用标准装备 ID。 |
| 经济 | 当前金币和运营资源状态。不要把未知经济写成 0。 |
| 行动值 | 战斗剩余行动值；与头像附近的其他数字不是同一字段。 |
| 转型 | 当前核心未出现或条件恶化时切换到替代路线。必须写清触发条件和代价。 |
| 事实 | 来源直接陈述、可按定位核对的内容。 |
| 作者建议 | 来源作者的玩法判断，不等同官方机制或普遍胜率。 |
| AI 推断 | 研究者根据多个证据推导的结论，必须显式标注且不能冒充来源事实。 |
| unknown | 客观证据不足。unknown 不是 0、空或“不存在”。 |

## 常见研究错误

- 把作者标题中的伤害数字推广为通用伤害；
- 把创作体验服数值直接当作正式服事实；
- 只写视频链接，不写结论对应的时间点；
- 用名字新造 ID，而不是查询 `standard-ids`；
- 为了消除冲突而删除其中一个独立来源；
- 把缺失的刷新、经济或装备阈值补成“看起来合理”的数字。
