- **修复**（单变量，只改显示）：
  - XAML：删除固定 `Height="760"` / `MinHeight="620"`，改为 `SizeToContent="Height"`（窗口高度随内容自适应，按钮行必在可视区内）。

- **状态**：✅ 已修复（待实机验证）

### 2. 云游戏窗口截屏黑屏 / 无法正常截取
- **根因**（对照交接总结逐项核实，总结**不准**——它声称 0.2.815 已有 `IsEffectivelyBlack`+`PrintWindow` 回退，实际 git head 中**完全不存在**，那是 0.2.816+ 的改动）：
  - `GdiGameCapture.CaptureAsync` 只有裸 `BitBlt` 从屏幕 DC 截取 `ClientArea`；云游戏用 GPU 合成渲染，BitBlt 拿不到 GPU 表面 → 黑/深灰坏帧（中心 RGB(32,32,32)）。
  - 云游戏浏览器被遮挡时 BitBlt 还会截到别的窗口内容。
- **修复**（`src/CurrencyWarsAssistant.Vision/GdiGameCapture.cs`）：
  - 新增 `IsEffectivelyBlack`（中心 60% 区域平均 RGB ≤ 60 判黑，阈值 60 覆盖 32 坏帧）。
  - 新增 `TryCaptureWithPrintWindow`：`PrintWindow(hwnd, dc, PW_RENDERFULLCONTENT=2)` 从窗口自身渲染内容截取（含 GPU 合成），再把整窗像素裁剪出客户区，保持帧尺寸与 `ClientArea` 一致（上层坐标换算不变）。
  - **云游戏源（`SourceKind == CloudBrowser`）直接优先走 PrintWindow**（不依赖屏幕可见性，遮挡也有效）；本地客户端 BitBlt 后黑帧才回退。
  - `MainWindow.OnCalibrateGameAreaClick` 与 `GameAreaCalibrationWindow.OnReloadPreview`：**云游戏浏览器不再切前台**（切前台会让 Edge 从全屏还原/缩小 → 窗口乱动）。
  - 新增测试：`GdiGameCaptureBlackFrameTests`（6 个：深灰坏帧/全黑/正常帧/边缘 UI 暗中心/阈值边界/中心 60% 采样区域）。
