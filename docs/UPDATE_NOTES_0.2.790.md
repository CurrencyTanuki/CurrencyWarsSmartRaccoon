# 0.2.790 更新说明（2026-08-03）

## 刷开局性能优化（用户 8/3 指定方案，三项全部完成）

### 1. 快速点击路径（主界面 → 开始本局）
- 从货币战争主界面点"开始货币战争"后，标准模式固定按钮快速连点
  （选标准博弈 → 进入所选模式 → 开始本局），**不再每步等待 2 帧稳定识别**，
  只用单帧确认页面已切换。
- **敌人概览保留稳定识别**：必须先确认敌人信息（3 阵营 + 4 词缀）后再点确认，不会因提速漏识别。
- 位面进度页"一出就点"：确认敌人概览后位面进度一出现立即点继续，动画继续播放。
- 超频博弈模式保持原有稳定识别路径，不受影响。

### 2. 投资环境识别提速
- 位面进度继续后，投资环境页**一出现即开始内容识别**（不再等页面 2 帧稳定）；
  识别循环自身仍有 2 帧投票稳定兜底，识别结果不变。

### 3. 备战页（1-1/1-2）大头优化
- 只缩短**可安全下调的保守等待**（每一项后面都有识别/验证循环兜底），
  **识别逻辑与输出结果完全不变**：
  - 进入 1-1 初始等待 1400ms → 800ms
  - 商店补员后回备战页 900ms → 600ms
  - 银河学者替换后重识别 500ms → 350ms
  - 部署/出售/Esc 后动作等待 500ms → 350ms（3 处）
  - 页面确认帧间 200ms → 150ms
  - 金币/占用复核帧间 300ms → 200ms（2 处）
- 拖拽时长（650ms）、备战席动画稳定等待（550ms）、连续 2 帧确认语义均**未动**。
