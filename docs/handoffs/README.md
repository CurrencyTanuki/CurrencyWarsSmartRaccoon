# 独立对话交接入口

固定模块入口：

- `project-control.md`
- `vision-recognition.md`
- `opening-reroll.md`
- `reward-stage.md`
- `ui-overlay.md`
- `data-knowledge-base.md`
- `testing-release.md`

新对话应先阅读对应固定入口；完成阶段性交付后可另按日期增加记录，但不能只在日期文件中修改项目全局状态。

本目录用于模块化交付，不保存聊天复述。任何新对话开始前先阅读：

1. `../PROJECT_STATUS.md`
2. `../ARCHITECTURE_BOUNDARIES.md`
3. `../DECISIONS.md`
4. 本目录中与任务对应的交接文件

## 建议拆分的独立对话

| 对话 | 主要输入 | 必须交付 | 集成门禁 |
|---|---|---|---|
| 数据 schema 与导入层 | 上游 raw JSON、当前 C# 数据模型 | schema、验证器、转换器、报告、fixture | 不覆盖 raw；运行时加载与引用测试通过 |
| 捕获兼容性 | WGC 代码、历史启动异常、目标 Windows 环境 | 后端选择策略、诊断、兼容测试 | 不启动游戏除非获授权；保持 `IGameCapture` 契约 |
| 页面识别基准 | 现有 25 张回放图和模板 | 多样本 fixtures、第二锚点、准确率报告 | 不改业务点击；危险页误判必须为 0 |
| 退出重刷恢复 | 退出/确认/结算截图与日志 | 有限重试状态机、单循环验收 | 不影响正向导航；有 `RecoveryCompleted` 实机证据 |
| 备战识别与布阵 | 1-1 截图、角色模板、站位规则 | 识别、计划、单步拖动验证 | 先观察后操作；每次拖动有源/目标变化证据 |
| 奖励关自动化 | 1-1、1-2、战斗、结算、投资策略截图 | 分段状态机和动作预算 | 默认实验关闭；每段单独 L4 后再串联 |
| UI/UX | 当前 XAML、产品安全文案 | 深蓝主题、实验标签、首次运行提示 | 不改任务语义；所有控件有暗色样式 |
| 发布工程 | 当前工作区和候选产物 | Git/版本/构建清单/许可证/发布说明 | 先确认历史来源，不删除用户文件 |

## 总控保留职责

以下事项不应完全委托给独立对话：

- 决定模块边界和依赖方向；
- 判断交付是否真正接入 `App.xaml.cs` 和主状态机；
- 给能力标注 L1/L2/L3/L4；
- 决定候选产物是否晋升；
- 协调上游数据文件的并发写入；
- 更新项目状态和关键决策。

## 交付文件命名

建议每个独立任务在本目录新增一个文件：

```text
YYYY-MM-DD_<module>_<short-topic>.md
```

内容使用 `HANDOFF_TEMPLATE.md`。已结束的交接文件保留，新的结论同步回 `PROJECT_STATUS.md`；不能只在 handoff 中修改项目全局状态。
