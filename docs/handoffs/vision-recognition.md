# 视觉识别与窗口捕获

## 模块目标

从目标游戏窗口安全获取客户区帧，并把像素转换为页面、文本、角色卡、商品和投资策略等带置信度的观察结果；为 Tasks 提供识别事实，不执行业务动作。

## 不属于本模块的内容

不决定是否保留开局、不选择刷取方案、不安排页面动作序列、不点击/拖动、不管理 UI，也不定义上游知识库 schema。

## 当前真实状态

WGC、模板匹配、Windows OCR、页面分类和角色卡识别均有实现并在 `App.xaml.cs` 接入。页面回放 fixture 覆盖 25 个正向样本；多数页面仍只有一个模板锚点，跨分辨率和负样本覆盖不足。

## 已实机验证

较早产物日志证明曾在 2560×1440 游戏窗口识别普通 HUD、指南、首页、模式、难度、敌人概览、投资环境和备战页。无法从文件确认这些日志使用的是当前 WGC 修复和 `live-test-30`，所以当前实现的 L4 状态为**尚未确认**。
