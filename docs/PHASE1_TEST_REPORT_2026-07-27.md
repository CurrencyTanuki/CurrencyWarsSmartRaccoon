## 未覆盖与风险

- WGC 历史上出现过 `CreateDirect3DDevice` 的 `InvalidCastException`；现有硬件→WARP 修复缺当前候选实机证据。
- 没有原生 1280×720、1600×900、2560×1440、3840×2160 × Win10/Win11 × 100/125/150% DPI 的完整矩阵。软件 resize 不能代替原生采集。
- WGC surface 与客户区边框裁剪、窗口动态 resize/frame-pool 重建仍需实机验证。
- 多数危险页面仍只有单锚点；缺少足够相似负样本、动画、hover 和遮挡样本。
- 角色金币视觉模板目前只有数字 3 和 7 的真实样本；零金币通过“购买后原槽不变”安全停止，而不是直接识别数字 0。
- 现有仓库没有有效 Git 元数据，无法给候选绑定 commit；本报告只能绑定文件哈希清单。
- 主界面尚未提供截图器后端选择及可视化 OCR/ROI/阈值校准。WGC 是唯一生产后端，GDI 尚未验证和接线。
