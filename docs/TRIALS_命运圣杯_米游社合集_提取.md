## ⚠️ 对我们之前结论的修正（务必看）

> **2026-08-26 二次核校更正**：经重新抓取并对照用户实读页面，`令咒决议·行为限制` 的奖励**并非 40经验**。原文标题虽被提取器标注"40经验"，但正文仅写"立即获得奖励"、无任何奖励列表；作者原话"有些多个奖励的任务可能奖励没列全，实在是刷不出来了"正指此类。真正的 **40经验/20免费刷新/2完美投影仪** 属于 **`令咒决议·行为禁锢`**。下文已据实更正。

1. **「五费聘用书出自令咒决议」是对的，但出处是回路过载，不是行为限制。**
   - `令咒决议·行为限制`(7330007)：奖励依本攻略**未列明**（仅"立即获得奖励"），代价 = 刷新价格+1金币（商店等级≥8解除）。**不含五费聘用书，也不能断言是40经验**。
   - 真正给 **2张五费聘用书** 的是 **`令咒决议·回路过载`**（诅咒，羁绊3层）：奖励多选一 = `40经验 / 2随机进阶装备 / 2五费聘用书`，代价 = **购买经验价格+1金币**（解除：累计刷新16次）。
   - 用户把「行为限制」和「回路过载」记混了。五费聘用书确实能从令咒决议系列里滚出来，但落在**回路过载**上。

2. **试炼奖励"是否可读"要分情况，不能一刀切。**
   - 多数令咒决议奖励攻略列得清楚（危险契约、行为禁锢、回路过载等），对玩家/客户端**可见可读取**。
   - 但**行为限制是已证实的例外**：作者没刷出来，只写"立即获得奖励"，奖励未知。这反而**重新印证本地 `trials.jsonl` 把 7330007 标成 `server_side/resolved:false` 是站得住的**——它的奖励确实没被干净解析。
   - 结论：软件识别逻辑对令咒决议系列**大部分可读（标题+已知奖励表）**，但**行为限制的奖励必须当"未知/开放"处理**，不可假设能读到具体内容。

3. **`奇迹代偿`的8个完美投影仪是【限时1节点】的。**
   - 原文：「立即获得**8个持续1节点的完美投影仪**」。代价是损失88战队生命值**和所有金币**。
   - 之前决策树写「8完美投影仪+本体→拖投影仪3星」没标时效，必须改成「拿到后须在**当前节点内**用完，否则消失」。

## 给决策树的修订待办（基于本文）

1. 试炼分支里「两五费聘书」的来源修正为：**王之财宝（多选一）/ 铸剑 / 再临仪式·四 / 令咒决议·回路过载（2张）**，并删除原先对行为限制含五费聘用书的假设。
2. 奇迹代偿节点补「**8投影仪限时1节点，须当节点用完**」。
3. 无限之釜节点升级为「**全三星圣杯角色**」，直接终局。
4. 行为限制/行为禁锢 = 刷新+1金诅咒；回路过载/超频/理想试炼 = 购买经验+1金诅咒，分开标记。
5. 令咒决议系列奖励**多数可读（标题+已知奖励表）**，但 **`行为限制`(7330007) 例外——奖励未列明、当未知处理**；不可一刀切假设全部可读。本地 JSON 把 7330007 标 server_side/resolved:false 是站得住的。
6. 述说原初 = 诅咒改件类（非祈愿），属「赤红/金色传说的进化前置」，对主线三星非必需，可标为可选。
