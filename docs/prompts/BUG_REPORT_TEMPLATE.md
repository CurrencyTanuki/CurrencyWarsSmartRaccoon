# 极简 Bug 反馈模板

复制对应模块提示词后，在末尾补下面内容。能写多少写多少，也可以只用一句自然语言描述；模块对话应主动检查最新日志和代码。

```text
我刚才实机测试发现一个 Bug：

发生在哪一步：
实际发生了什么：
我原本希望它怎样：
是否每次都能复现：
相关截图或日志路径（如果有）：

请先检查最新 logs、现有实现和测试，判断根因及模块归属。能在本模块内解决就做最小修复并完成 L1/L2/L3 验证；如果实际属于其他模块，不要越界修改，直接告诉我应该把它发给哪个模块。
修复后请给我一份简短的人工复测步骤，不要自行启动或操纵游戏、BGI 或 Windows 桌面。
```
