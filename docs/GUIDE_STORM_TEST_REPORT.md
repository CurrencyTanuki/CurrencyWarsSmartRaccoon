## 一、真根因（子代理独立复核，置信 ~90%）

**触发器**：赛季/活动刷新（指南页"剩余时间 3天19小时"≈09-07 刷新，与 09-08 晨 1.2.123 同类故障时间吻合）→ **星际和平指南窗口默认页签变为"每日实训"页（每日任务/活跃度页，第一页签选中带红点）且标题背景改为彩色活动渐变**。

- **缺陷 A（识别缺口）**：打开指南 → 默认落在**每日实训页 → 该页不在识别表** → guide-shell-title 模板匹配仅 0.769<0.9（标题背景渐变所致，识别层正确判 Unknown）→ **OCR 兜底**（TryClassifyGuidePageByOcrAsync，阈值 0.72）识别"星际和平指南"返回 guide_shell——日志中 98-99% 是 **OCR 置信度而非模板分**。
- **缺陷 B（导航验证/坐标）**：点"切换到第三个页签"(803,281)（navigation-flow.json 坐标换算正确，但**贴页签下沿**）→ 有时成功进入旷宇纷争（08:07-08:38 的 13 个 run 产出 guide_currency_wars ×13，模板 0.967 稳过）、有时页面停留/跳回每日实训 → **不在识别表 → Unknown → Esc×3 无效（每日实训页吃 Esc）→ TimedOut → M8 重开 → 死循环 2 小时**。
- **缺陷 C（入口）**：07:55 第三局金尽弃局链失败后，盲点直通把引擎落在 **normal_hud（游戏大厅）而非 currency_wars_home** → M8 按坑 41 决策树走"主界面→指南→货币战争"链 → 首次长时间踩进缺陷 A/B 雷区（阶段 A 及历代会话起点都是 currency_wars_home，走"开始本局"直进不经过指南）。

**排除项**：识别层/捕获层/分析层全程存活（08:41 后日志持续成功识别"游戏主界面 69.1%/星际和平指南 99.1%"；后段 run 无 analysis JSON 只因流程未走到产出节点）；活动红点不在锚点区域（旷宇纷争帧模板 0.902/0.967 均过阈值）。
