# Release 1.0.0（货币战争智能狸 · 首批群友需求修复版）

发布日期：2026-08-23
渠道：官网（主）https://taskflowai.cn/currencywar

## 变更说明

本版集中处理群友反馈的第一批问题，覆盖刷开局核心逻辑 + 一批可独立控制的开关。

**Bug 修复**
- 出战弹窗确认：每次点出战后都检测弹窗并自动确认，不再因内存名单误判而卡死
- 英雄登场（投资环境）开局保护 1 号位角色不被自动卖出
- 上下配置完全隔离：上方"全局投资环境"与下方"刷取方案"互不影响；下方新增"开始刷开局（仅按下方刷取方案）"按钮
- 开始刷开局/记录时强制开启节点历史窗与日志窗鼠标穿透（避免误点节点历史区导致自动停止）
- 开始刷开局/记录前自动重新识别游戏窗口（游戏重开后句柄变化也能适配）

**新增独立开关（设置页）**
- 预设优先上场角色（默认开）
- 刷到目标开局后是否停下（默认关 = 命中即停，不进行 1-2 干预）
- 对局中途点"开始刷开局"是否执行（默认关 = 不执行）
- 检测到已有进行中对局时自动停下（默认开）
- 复盘证据：详细诊断日志保存开关（默认关）

**逻辑修正**
- 已配置投资策略时命中后必定进入奖励关去刷该策略；未配置时按奖励关开关决定（默认关 → 布阵后停在 1-1）
- 刷开局过程中检测到已有对局立即停下，不误碰既有对局、不误结算
- 1-2 投资策略自动化：配置目标策略后，命中开局自动打奖励关并在投资策略页自动选中目标策略，命中才停
