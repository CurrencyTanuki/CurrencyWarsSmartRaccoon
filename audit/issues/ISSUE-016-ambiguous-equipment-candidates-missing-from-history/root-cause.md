# ISSUE-016 根因与修改边界

状态：修前真实图红测已闭环，根因确认。

## 候选根因

共享 `gen_report.py` 把装备槽简化成“单一已知装备图标 / 空框”二态，没有消费正式模型已保存的 `CandidateEquipmentIds`。真实截图分析、pending 与 canonical archive 均保留066/105；同一数据进入 renderer 后，角色44三个槽全部变成相同空框。因此 Unknown/ambiguous 的有效部分识别确定在最终投影阶段丢失。

## 计划的最小边界

- 只修改共享 `gen_report.py` 和本项专门回归测试；
- 从既有 `data/runtime/1.0.0/4.4/equipment/equipment.json` 只读加载 ID→中文名；
- Unknown 且有候选时保留问号槽，并显示玩家可读候选中文名；
- 映射缺失时显示“未知装备（待核对）”，不得直接显示内部 ID；
- Empty 仍为空槽；本项不改变识别阈值、候选顺序、状态模型、序列化、装备资产或财富冲突。

## 不纳入本项

- 已确定单一装备仅有图标、缺少可见中文名的问题；
- 物品栏 `InventorySlots` 候选展示；
- 特殊装备名称展示；
- 财富×2、垃圾袋分类、星徽秘典建模；
- 全部157项在两个界面的逐项实机展示。
