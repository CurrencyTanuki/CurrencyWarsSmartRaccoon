> 目标：做一个**单文件 HTML 页面**，上传底图 → 把自己动手把角色框/装备框拖到精确位置 → 微调数据保存成 `JSON` → 软件以后直接读取用。

## 一、你要的东西（需求重述，确认我没理解偏）

1. **上传图片**，识别框全部悬浮显示在图片上。
2. 可切换**后台人口 6 / 7 / 8 / 9** 四种情况，**切换时角色框和装备框必须整体同步调整**（不是只改牌子，是所有框跟着一起动）。
3. 所有角色框、装备框的**初始位置 = 当前程序里正在用的位置**（第一帧就完全贴合），并且**每个框的 4 个顶点都能手动拖动**。
   - **装备框用 A 套**（固定三槽 `0.03/0.39/0.72`(前)、`0.03/0.34/0.68`(后)、槽宽 0.26 卡宽、槽高 0.26 卡高、y中心=卡y+1.08卡高）。B 套 / mode2 / mode3 不要了。
   - **后台角色框必须是"斜视四边形"**：你拖的是原图上那个斜的四边形，4 个顶点。
     **软件识别时**，会像现在程序一样用 warp 单应，把这个斜四边形**自动转成正视矩形**再去识别。你在页面上拖斜四边形时，页面要**实时预览**"拉正之后长什么样"（即 4 顶点拖动时，拉正结果同步刷新）。
4. 操作面板上要有**像素级微调按钮**：左 / 上 / 下 / 右，每点一次移动 1 像素。用来做比拖动更精确的定位。
5. 工作成果能**正确、完整地保存下来**（JSON），并能被重新读取回来继续调。

## 二、保存格式（JSON 结构）

```jsonc
{
  "version": 1,
  // 前台角色格：4 个直角矩形（正视平面，轴对齐）。存归一化坐标(0~1)。
  "frontSlots": [
    { "x": 0.3547, "y": 0.3046, "w": 0.0667, "h": 0.1296 },
    { "x": 0.4307, "y": 0.3046, "w": 0.0635, "h": 0.1296 },
    { "x": 0.5063, "y": 0.3046, "w": 0.0625, "h": 0.1296 },
    { "x": 0.5802, "y": 0.3046, "w": 0.0625, "h": 0.1296 }
  ],
  // 后台：锚点驱动（下面细讲），8 个字段即可表达 6/7/8/9 全部情况。
  "backAnchor": {
    "topLeftX":  0.17865, "topRightX":  0.24271, "topY":    0.55556,
    "botLeftX":  0.16615, "botRightX":  0.23229, "botY":    0.68056,
    // 槽间距(px, 1920参考系)：6/7/8/9 共用同一间距(由你的标定推出 dTop=133.5)
    "slotPitchTop": 133.0, "slotPitchBot": 136.3
  },
  // 装备 A 套：每行前/后台各自的三个槽比例参数
  "equipment": {
    "frontStarts": [0.03, 0.39, 0.72],
    "backStarts":  [0.03, 0.34, 0.68],
    "slotW": 0.26, "slotH": 0.26, "yCenterRatio": 1.08
  }
}
```

> 为什么后台存"锚点"而不是"每个格子的 4 顶点"：程序源码就是**由 6 个锚点（最左槽的左上/右上x、左下/右下x、TopY、BottomY）+ 恒定槽间距**推导出 6/7/8/9 不同格数（中轴 960 对称铺开）。存锚点，**才能和程序完全一致地同步调整**，也才符合"切换 6/7/8/9 一起动"。前台是 4 个独立矩形。

## 四、页面交互设计

1. **顶部**：上传图片按钮 + 后台人口选择器（6/7/8/9，默认 7）。
2. **中间画布**：图片上叠加斜四边形（后台，可拖4顶点）＋ 直角矩形（前台、装备A套三槽，可拖4顶点）。
   - 选中的框高亮；非选中的用对比色。
   - **后台切换 6/7/8/9 时**：按锚点+间距重算所有后台四边形与后台装备框，同步整体变化。
   - **拖后台任一格子的 4 顶点时**：按"该格在行内的相对比例"映射回锚点 → 整行所有格跟着同步变化（因为程序是锚点驱动，不能只拖一格）。同时右侧**实时预览拉正后的正视效果**。
3. **右侧操作面板**：
   - 当前选中对象（前台角色格 1/2/3/4、后台格、某装备槽……）。
   - 像素级按钮：**左 ◀ / ▲ 上 / ▼ 下 / ▶ 右**（1px 步进，可按住连续）。
   - 显示当前坐标数值（归一化 + 像素双显示）。
   - **保存到 JSON**（下载 or 直接写入固定文件路径）＋ **读取 JSON**（回载继续调）。
4. **底部/悬浮**：拉正预览小窗（后台行 warp 后长什么样）。

## 五、"拉正"在页面里怎么算

页面里用 Canvas 2D 的 `setTransform` 实现**透视单应**：把后台整行斜四边形映射到轴对齐矩形。Warp 数学和 `BackRowPerspectiveGeometry.ComputeRowHomography` 一致（4 点求透视变换）。这样预览的就是软件识别时真正看到的样子。
