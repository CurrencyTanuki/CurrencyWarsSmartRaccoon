# 币站开局小助手：开局页面与识别区域

## 1. 样本与坐标约定

本次分析使用 7 张截图，按文件名时间排序：

1. `Screenshot 2026-07-24 013506.png`
2. `Screenshot 2026-07-24 013541.png`
3. `Screenshot 2026-07-24 013547.png`
4. `Screenshot 2026-07-24 013558.png`
5. `Screenshot 2026-07-24 013604.png`
6. `Screenshot 2026-07-24 013612.png`
7. `Screenshot 2026-07-24 013625.png`

原图由 Windows `Win+Shift+S` 手工框选整个屏幕取得，文件尺寸均为 `2559×1439`。少的一行和一列来自手工框选误差，实际显示环境按 `2560×1440`、16:9 处理。项目内部使用 `1920×1080` 标准坐标：

```text
standardX = sourceX × 1920 / sourceWidth
standardY = sourceY × 1080 / sourceHeight
```

截图分析阶段按 `2560×1440 → 1920×1080` 换算。程序运行时会直接读取游戏窗口客户区并换算，不使用手工截图边界或整个桌面坐标，因此这一像素误差不会进入正式逻辑。

当前坐标是根据第一批手工截图整理的初始区域，后续需要用程序实际捕获的原始游戏帧做一次校准。所有点击使用区域中心，不依赖单一像素。

截图左下角包含 UID。完整截图不得直接提交到公开仓库；调试截图保存前应遮盖标准坐标区域 `[0, 1025, 235, 55]`。

顶部中央持续出现的圆形图案可能是鼠标指针或外部覆盖层，不应作为任何页面的识别锚点。

## 2. 页面流程

```text
货币战争首页
  → 点击“开始「货币战争」”
模式选择页
  → 点击“进入标准博弈”
职级难度页
  → 点击“开始对局”
敌人概览页
  → 读取敌人阵营与四个敌人词缀
  → 点击“下一步”
位面进度页
  → 点击空白处继续
投资环境页
  → 读取三个投资环境候选
  → 选择候选，必要时先使用一次刷新
  → 点击“确认”
1-1 备战页
```

这说明“敌人负面条件”和“投资环境”是两个独立识别阶段，不能使用一个截图读取器同时处理。

6. 刷新后等待卡片动画停止，重新进行双帧识别；

## 10. 当前刷开局状态机

根据截图，正确的首版状态机应为：

```text
FindGameWindow
→ DetectCurrencyWarsHome
→ ClickStartCurrencyWars
→ DetectModeSelection
→ ClickEnterStandardMode
→ DetectRankDifficulty
→ ClickStartRun
→ DetectEnemyOverview
→ ReadEnemyFactionsAndModifiers
→ EvaluateEnemyRules
    ├─ 不可接受 → AbortAndRestart
    └─ 可接受 → ClickNext
→ DetectPlaneProgress
→ ClickBlankToContinue
→ DetectInvestmentEnvironment
→ ReadThreeInvestmentOptions
→ EvaluateInvestmentOptions
    ├─ 有可接受选项 → SelectOption → Confirm
    ├─ 无可接受选项且可刷新 → Refresh → ReadAgain
    └─ 刷新后仍不可接受 → AbortAndRestart
→ DetectPreparation1_1
→ KeepAndNotify
```

## 11. 尚缺的关键截图

目前 7 张图足以定义“正向进入第一局”的流程，但还不足以完成真正的循环重刷。仍需要：

1. 从敌人概览页退出本局时出现的页面；
2. 从投资环境页退出本局时出现的页面；
3. 1-1 备战页左上退出按钮点击后的菜单；
4. 放弃本局或重新开始的确认弹窗；
5. 确认退出后返回到哪个页面；
6. 投资环境点击刷新后的动画结束画面；
7. 投资候选选中与未选中的清晰对照；
8. 每个按钮不可用、可用及鼠标悬停状态。

没有这些页面时，可以安全完成正向导航和信息识别，但不能可靠完成“发现坏开局后自动退出并重新开始”的闭环。

## 12. 识别技术选择

| 内容 | 推荐方式 |
|---|---|
| 七种页面分类 | 每页 2 个稳定锚点模板 |
| 固定按钮 | 模板匹配 + 固定 ROI |
| 敌人阵营名称 | 固定 ROI OCR + 卡面分类 |
| 四个敌人词缀 | 固定 ROI OCR + 词缀图标模板 |
| 三个投资候选名称 | 固定 ROI OCR + 大图标模板 |
| 投资候选描述 | OCR，仅用于名称不确定时 |
| 剩余刷新次数 | OCR 或数字模板 |
| 候选选中状态 | 边框亮度/颜色检测 |
| 卡片动画结束 | 连续帧差异检测 |
| 1-1 角色卡 | 卡槽检测 + 头像分类 |
| 按钮点击结果 | 下一页面锚点验证 |

第一批只有单张样本，不能据此确定最终模板阈值。每个页面至少还需要普通状态、悬停状态、动画刚结束状态和第二次进入状态的截图。
