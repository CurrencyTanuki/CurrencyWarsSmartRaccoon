# 货币战争智能狸 0.2.755 更新说明

## 启动和点击响应修复

- 加入单实例保护：软件已经启动或正在启动时，再次双击只会唤醒已有窗口，第二个进程立即退出，不再因为连续点击叠加多个初始化进程。
- 启动窗口提高到前台并保持可见，让首次点击尽快得到视觉反馈。
- 游戏数据、页面配置、识别模板目录和社区配置改为并行读取，缩短串行初始化路径。
- 大型“开局词条”编辑区改为按需加载；主窗口首次布局不再创建和测量整套复杂词条控件。未加载编辑区时，刷开局仍沿用已保存配置。
- 使用声明改为非模态窗口，不再阻塞主窗口按钮。
- “开始刷开局”和“开始记录”先更新运行状态并让 WPF 完成一帧重绘，再执行窗口发现、悬浮窗创建和后续任务；按钮命令本身继续保持防重复执行。
- 悬浮窗创建移到较低的界面调度优先级，避免吞掉开始按钮的首帧反馈。
