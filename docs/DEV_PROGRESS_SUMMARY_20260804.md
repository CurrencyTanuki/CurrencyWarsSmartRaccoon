## 一、项目是什么

面向《崩坏：星穹铁道》"货币战争"玩法的 Windows 桌面辅助工具。货币战争是**独立于模拟宇宙体系的玩法**。玩家在货币战争中需要反复刷开局（随机投资环境/敌方词条/投资策略组合），目标是刷到符合自己阵容偏好的开局——这是高度重复、耗时的过程。本工具自动完成：

- 识别开局信息（敌方阵营、负面词条、三个投资环境候选）
- 按用户配置筛选（可精确指定要什么/不要什么）
- 不合格自动退出重开；合格后自动打完前两层奖励关
- 全程自动，用户只需挂机

**本质**：把"刷初始/刷开局"这种又肝又无聊的重复操作自动化——在抽卡/肉鸽类游戏里，这类需求**真实且普遍**。

技术栈：C# / .NET 8 / WPF / OpenCV（模板匹配）/ Windows OCR，单机本地运行，不联网不收集用户数据。

## 三、目标用户群分析（社区潜力的基础）

### 用户画像
- **星穹铁道玩家**（国服活跃玩家数千万级）
- 其中**玩货币战争模式**的：独立玩法，核心玩家**不到 100 万**，以**强度党**为主
- 这类玩家特征：**愿意为强度投入时间**、对"刷开局"有真实痛点、活跃于 B 站/贴吧/QQ 群

### 需求强度
- 刷开局是**公认痛点**（贴吧/B 站有相关讨论，但讨论并不多）
- 有竞品：**StarRailAssistant**（星铁工具），但其功能定位与我们的差距较大
- 本工具**免费 + 开源**，比竞品门槛低（无需付费/会员）

### 规模估算（供 Codex 参考）
- 星铁活跃玩家数级：数千万（国服）
- 玩货币战争的核心玩家：不到 100 万
- 其中**愿意用辅助工具**的：数千~数万
- **潜在社区规模（QQ 群/使用者）：几千到几万**是现实的量级
